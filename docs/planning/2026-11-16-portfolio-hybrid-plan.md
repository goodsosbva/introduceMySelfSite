# 기존 디자인에 두 참고 사이트의 느낌을 섞는 기획

최신 사용자 요청 반영: 원본을 그대로 두고 태그만 추가하는 v3보다 시각적 변화를 준다. 기존의 정체성을 유지하며 기술, 프로젝트와 자격증의 표현 방식을 바꾼다.

## 유지하는 디자인

구프로젝트의 폴라로이드 사진과 사진 링크 동작, 대화형 소개와 Profile, 흰 바탕, 남색 큰 영문 제목, 푸른색 마침표, 넓은 여백을 유지한다. Projects → Skills → Certificates → Contact 순서로 이어진다.

## 섞는 요소

| 영역 | 가져오는 느낌 | 사용자 사이트에 적용 |
| --- | --- | --- |
| 기술 | [배기영 사이트](https://portfolio-2026-tau-five.vercel.app/)의 밑줄 탭, 핵심 역량 설명과 로고 격자 | 탭 이름은 회사 실무 / CityWatch / Common Tester 유지. 해당 사용처의 기술만 로고 타일과 짧은 경험 설명으로 표시. |
| 프로젝트 | 배기영 사이트의 미리보기와 역할 정보, [정연희 사이트](https://yeonhee7935.github.io/)의 펼쳐 보는 프로젝트 | 기존의 번호와 제목, 구분 배지는 유지. 열면 미리보기와 담당 내용, 기술, 기존 상세 링크를 보여준다. |
| 자격증 | 정연희 사이트의 옅은 배경과 간결한 흰 행 | ADsP를 포함한 다섯 자격증을 이름과 취득월만 표시. |

단순히 같은 색을 쓰는 수준을 넘어, 기술을 보는 방식과 프로젝트를 읽는 방식을 섞는다. 참고 사이트의 이름이나 콘텐츠는 옮기지 않는다.

## 프로젝트

처음에는 공통 UI 한 개만 열린 모습으로 보여준다. 번호, 구분, 제목과 한 줄 요약은 접혀 있어도 보인다. 열린 항목은 왼쪽 미리보기, 오른쪽 담당 내용으로 구성한다. 기술 칩과 기존 상세 페이지 연결을 제공한다.

- 공통 UI: 테이블과 버튼 개발 및 개선 참여, Storybook 사용 가이드와 사용 예. 미리보기는 기존 상세의 재구성 예시를 활용하고 구성 예시라고 표시한다.
- CityWatch FE Lab: 도시 안전 관제와 X-Ray, 기술 실습. 펼쳤을 때 기존 실제 캡처 사용.
- Common Tester: 요구사항 근거, 생성된 테스트와 실행 결과 연결. 펼쳤을 때 기존 실행 결과 캡처 사용.

원본의 설명을 축약할 수 있으나 역할 범위를 확대하거나 성과 수치를 만들지 않는다. 펼치기는 표준 HTML details/summary로 구현 가능하다. 제목, 요약과 상세 페이지 링크는 키보드로 이용할 수 있어야 한다.

## 기술

탭을 누르면 아래 내용이 바뀐다. 활성 탭에는 푸른 밑줄을 사용한다. 원본의 기술 사용처 분류와 전체 기술명은 유지한다.

| 탭 | 기술 | 짧은 경험 설명 |
| --- | --- | --- |
| 회사 실무 | React, Vue 3, TypeScript, Ant Design Vue, pnpm, Nx, Storybook | 업무 화면과 공통 UI 개발. 컴포넌트 사용 가이드와 모노레포 구성. |
| CityWatch | React, Next.js, TypeScript, Redux, OpenLayers, Module Federation | 도시 안전 관제 화면. 지도와 상태 공유, 기술 구현 탐색. |
| Common Tester | React, Python, LangGraph, RAG, Playwright | 요구사항 근거부터 생성된 테스트와 실행 결과까지 연결. |

데스크톱은 네 열의 작은 로고 타일을 사용하고, 모바일은 두 열로 바꾼다. 로고에 기술 이름을 함께 표시한다. 회사 실무의 React는 기존 메인에 기록된 사용 기술이며 구체적인 범위를 과장하는 설명은 붙이지 않는다. 기본 버튼과 소량의 JavaScript로 구현하며 새 탭 라이브러리는 추가하지 않는다. 활성 탭 표시, 방향키 이동과 선택된 패널의 관계를 접근성 속성으로 제공한다.

## 자격증

아주 옅은 회청색 배경에 흰 행 다섯 개를 둔다. 왼쪽은 명칭, 오른쪽은 취득월이다.

| 자격증 | 취득월 |
| --- | --- |
| ADsP | 2026.11 |
| CKA | 2026.01 |
| SQL개발자(SQLD) | 2025.04 |
| 리눅스마스터 2급 | 2023.07 |
| 정보처리기사 | 2021.08 |

ADsP는 사용자가 확인했다. 나머지는 기존 archive 백업의 기록을 따른다. 증서 번호는 노출하지 않는다.

## 구현 범위와 검토

이번 산출물은 기획서와 이미지 시안이다. 실제 구프로젝트는 수정하지 않는다. 구현 단계에서는 기존 HTML/CSS와 표준 요소, 소량의 JavaScript로 작업하며 요청된 Ponytail full 기준을 따른다.

확인할 사항은 기존 상단의 유지, 탭 전환과 키보드 탐색, 프로젝트 펼치기와 기존 상세 링크, 390px에서의 타일 및 자격증 줄바꿈이다. 새 프레임워크나 과도한 추상화는 필요하지 않다.

이미지는 실제 캡처가 아닌 내장 image_gen의 구성 제안이며, v3 시안을 기준 이미지로 편집한다. 생성 프롬프트는 `2026-11-16-portfolio-hybrid-image-prompt.md`에 기록한다.

최종 시안: `portfolio-hybrid/hybrid-design.png`. 현재 보이는 상태는 공통 UI 프로젝트 펼침, 회사 실무 기술 탭 선택이다. 실제 구현에서는 접힌 두 프로젝트도 요약과 기술을 충분히 읽을 수 있도록 두 줄 이상을 허용하고 모바일에서는 한 열로 배치한다. 로고는 이미지 생성 결과를 그대로 자산으로 사용하지 않고 실제 기술의 공식 로고로 교체한다.
