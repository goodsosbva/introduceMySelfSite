## 사진의 실제 동작

`profile-card.js` 전체를 확인했다. 마우스 진입과 키보드 포커스에서 GitHub, 티스토리, 노션 링크가 열린다. 가로 12px 이상 드래그하면 열리고 드래그 종료 후 고정된다. 클릭은 고정을 전환한다. 바깥 클릭이나 Escape로 닫는다. 이력서 PDF 링크는 hidden 상태이며 실제 표시되는 링크가 아니다.

## 상세 페이지에서 확인한 내용

- `case-common-table.html`: 로그 조회와 장비 목록의 재구성 예시, 공통화 전후 설명, Storybook 가이드, 슬롯을 이용한 상태 태그 코드. 테이블과 버튼 개발 및 개선, 모노레포와 패키지 분리, 가이드에 기여했다고 명시됨.
- `case-citywatch.html`: X-Ray, Module Federation과 Monorepo 실습, 상태 관리와 검증, 지도와 3D, 연결 복구, 렌더링, 패키지와 런타임 연결. 실제 실습 캡처와 GitHub 링크가 있음.
- `case-common-tester.html`: 근거 검색부터 테스트 실행 결과까지 5단계 흐름. 테스트 통과 6개와 정책 미확인 6개를 구분함. 결과 캡처와 GitHub 링크가 있음.
- `career-experience.html`: 회사 세 곳의 화면과 담당 범위가 별도 정리되어 있음. 메인에 상세 내용을 모두 복제할 필요가 없음.

## 이전 시안에서 원본을 벗어난 부분

1. 사진 크롭을 정사각형에서 세로 사진으로 바꿈.
2. 인사말의 문구, 글꼴과 줄바꿈을 임의 변경함.
3. 프로젝트 행에 큰 썸네일을 삽입해 원래의 텍스트 목록 구성을 바꿈.
4. 기술의 기존 사용처 분류를 Frontend / Workflow / Lab으로 교체함.
5. 원래 없는 세로 구분선, 배경 상자와 개별 이동 링크를 추가함.

## 다시 정한 변경 범위

원본 상단과 Profile은 그대로 둔다. Projects의 기존 행에 기술 네 개 정도를 작은 텍스트 태그로 한 줄만 추가한다. 제목, 설명, 구분 배지, 행 전체 링크와 화살표를 유지한다. Skills의 기존 세 분류와 기술명 전체를 유지하고 슬래시 문자열만 줄바꿈 가능한 작은 기술 태그로 바꾼다. Skills와 Contact 사이에 이름과 취득월의 자격증 다섯 행을 추가한다. 기존 상세 페이지와 동작은 유지한다.
