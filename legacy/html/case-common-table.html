02 / BEHAVIOR

기본 기능 일관성

필터, 정렬, 표시 행, 셀 렌더링과 페이지 UI를 한 진입점에서 연결합니다. 화면 설정에 따라 필요한 기능을 선택합니다.

코드 근거 filterData → sortData → getCurrentPageData, TableBodyCell, TablePagination

03 / REUSE

구현 재사용

장비 목록은 bodyCell 슬롯으로 상태를 그리고, 로그 조회는 sort-change 이벤트를 서버 정렬에 연결하며 같은 SharedTable을 사용합니다.

코드 근거 DeviceTable.vue, LogTable.vue

설계 참고: Atlassian Design System, Carbon Design System, Vue slots. 위 자료는 일반적인 설계 근거이며, 이 사례의 적용 근거는 두 사용 화면과 팀 코드입니다.

04 / TRADEOFF

득과 실, 교훈

득

반복되는 UI 기준과 구현을 한곳에 모아, 여러 화면을 같은 기준으로 만들고 개선할 수 있는 토대를 마련했습니다.

실

공통 코드의 결정은 이를 사용하는 모든 화면에 영향을 줍니다. 화면별 요구를 공통 코드에 계속 더하면 인터페이스가 복잡해지고 변경 비용도 커집니다.

교훈

공통 컴포넌트는 여러 화면에서 동일하게 유지할 규칙을 책임져야 합니다. 화면마다 달라지는 데이터 조회와 상태는 각 화면에 남겨야 공통 기준을 명확하게 유지할 수 있습니다.
