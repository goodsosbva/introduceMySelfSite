# 권현성 자기소개 사이트 2026 11 03

기존 사이트를 보존하고 이 폴더에서 리뉴얼합니다.

- 기준: 기존 청색 디자인과 서비스 화면 → 담당 기능 → 공통 구현
- 대표 사례: 클라우드 관리 서비스에 사용되는 공통 테이블과 재사용의 이점
- 회사별 화면: 오케스트로의 서비스 구성도, 카수리의 예약 흐름 재구성, 뉴스젤리의 보관 이미지와 사용자 흐름
- 개인 프로젝트: CityWatch 실행형 실습
- 협업에 사용한 테스트 생성기: Common Tester
- 메인, 경력, 세 상세 기록을 PC와 모바일에서 확인했습니다. 실제 수정 화면은 screenshots 폴더의 JPG 파일에 있습니다.

## 열기

`index.html`을 브라우저에서 열면 됩니다. 별도 패키지 설치가 필요하지 않습니다.

로컬 서버를 사용하려면 이 폴더에서 `python -m http.server 8767`을 실행한 뒤 `http://localhost:8767`을 엽니다.

## 구성

- `index.html`: 메인
- `career-experience.html`: 회사별 서비스 화면과 담당 기능, 공통 UI 기여
- `career-portfolio.html`: 구현 기록 목록
- `case-common-table.html`: 공통 테이블 구현과 재사용의 이점
- `case-citywatch.html`: 브라우저 실행형 실습
- `case-common-tester.html`: 요구사항부터 테스트와 실행 결과
- `assets`: 기존 디자인에서 이어받은 스타일, 설명용 테이블 예시, 프로젝트와 협업 도구의 기존 실행 이미지

공통 테이블 동작 예시는 가상 데이터 기반의 독립 재구성입니다. 실제 프로젝트 타입 발췌는 별도 표시했습니다. 프로젝트와 도구의 실행 이미지는 보관된 기존 실행 자료이며, 이번 리뉴얼에서 원본 서비스를 새로 실행한 결과가 아닙니다.

오케스트로와 카수리의 구성도는 설명용 재구성입니다. 뉴스젤리 이미지는 기존 포트폴리오 보관 자료이며 Vue 전환 전후 비교 자료가 아닙니다.
