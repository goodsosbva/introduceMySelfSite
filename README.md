# 권현성 | 프론트엔드 개발자

프론트엔드 개발자 권현성의 자기소개와 경력, 프로젝트를 소개합니다.

## 사이트 열기

[자기소개 사이트](html/index.html)

브라우저에서 `html/index.html`을 열어 확인할 수 있습니다. 별도의 설치는 필요하지 않습니다.

## 주요 페이지

- `html/index.html`: 자기소개, 경력과 프로젝트 목록
- `html/career-experience.html`: 회사별 경력
- `html/case-common-table.html`: 공통 UI 사례
- `html/case-citywatch.html`: 프론트엔드 기술 학습 프로젝트
- `html/case-common-tester.html`: 협업에 사용한 테스트 생성기
