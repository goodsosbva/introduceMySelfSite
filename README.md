# 권현성 | 프론트엔드 개발자

사용하기 쉬운 화면과 함께 개발하기 좋은 구조를 고민합니다.
프론트엔드를 중심으로 필요한 기술을 배우고 직접 적용하며 개발의 폭을 넓혀가고 있습니다.

## 소개

클라우드 관리 화면과 여러 팀이 사용하는 공통 UI 개발에 참여했습니다.
이 저장소에는 회사에서 맡았던 일과 기술을 직접 적용하며 만든 프로젝트를 정리했습니다.

## 프로젝트

### [공통 UI](legacy/html/case-common-table.html)

공통 UI TF에서 테이블과 버튼의 개발과 개선에 참여했습니다. 여러 업무 화면에서 공통 테이블을 사용하는 방식과 Storybook 사용 가이드를 소개합니다.

### [CityWatch FE Lab](legacy/html/case-citywatch.html)

도시 안전 관제를 주제로 여러 프론트엔드 기술을 직접 적용한 개인 학습 프로젝트입니다. 상태 관리, 지도, 실시간 통신, 모노레포와 Module Federation 등의 구현 구조를 살펴볼 수 있습니다.

### [Common Tester](legacy/html/case-common-tester.html)

협업에서 테스트 생성에 사용한 도구입니다. 요구사항의 근거부터 Playwright 테스트와 실행 결과까지 연결하는 흐름을 소개합니다.

## 경력

- **오케스트로**: 모니터링, 인프라 관리, 서비스 신청 화면과 공통 UI 개발 참여
- **카수리**: 정비 서비스 선택과 예약 화면 개발
- **뉴스젤리**: 꼬맨틀 화면의 Vue 전환

[회사별 경력 살펴보기](legacy/html/career-experience.html)

## 사이트 실행

별도 설치 없이 [legacy/html/index.html](legacy/html/index.html)을 브라우저에서 열 수 있습니다. 로컬 서버를 사용하려면 저장소 루트에서 다음 명령을 실행합니다.

```bash
python -m http.server 8000 --directory legacy/html
```

브라우저에서 `http://localhost:8000`으로 접속합니다. 사이트는 HTML, CSS, JavaScript로 구성되어 있습니다.
