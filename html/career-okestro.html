오케스트로.

자원마다 달라지는 생성 조건을 운영자가 입력하고 확인할 수 있는 클라우드 관리 화면으로 구현했습니다.

기간
2023.09 — 현재
역할
Frontend Developer
제품
클라우드 관리 플랫폼

REPRESENTATIVE WORK

자원 유형별 생성 폼

01 / 상황

클라우드 자원 유형에 따라 생성 화면의 입력 항목과 검증 조건이 달랐습니다.

02 / 구현

유형 선택에 따라 입력 컴포넌트, 기본값, 검증 조건을 분기했습니다. 생성과 수정 모드별로 초기값과 제출 데이터를 구성했습니다.

03 / 동작 결과

선택한 유형과 작업 모드에 맞춰 폼이 달라지고, 각각의 제출 데이터가 만들어지도록 했습니다.

SCOPE

담당한 화면과 상태

프로비저닝

클라우드 자원 생성 흐름과 유형별 입력 폼을 구현했습니다.

모니터링

알람 정책 생성 및 수정, 알람 로그 조회와 통계 화면을 구현했습니다. 기간, 심각도, 플랫폼, 자원 유형 등의 검색 조건을 API 파라미터와 연결했습니다.

인프라 관리

장비 등록과 조회, 권한, 로딩, 빈 값, 에러 상태를 처리하고 공통 테이블과 버튼을 개선했습니다.
