Case 01 / Common UI

반복되는 화면 문제를 공통 패턴으로 바꾸기

문제

화면마다 컬럼 설정과 상태 표현과 액션 로딩을 다르게 처리해 사용성과 유지보수성이 흔들렸습니다.

구현

컬럼 리사이즈, 컬럼 표시 제어, 고정 컬럼, 정렬 상태를 테이블 공통 기능으로 개선했습니다.

확장

검색 필터, 날짜 필터, 서버 페이지네이션을 같은 흐름으로 묶고 긴 텍스트, 링크 셀, 상태 태그를 재사용하게 했습니다.

기준

버튼 로딩, 비활성 조건, 빈 값과 에러 상태까지 화면마다 같은 언어로 보이게 했습니다.

  • Loading
