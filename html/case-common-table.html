02 / WHY SHARED UI

반복되는 기능을
공통으로 관리했습니다.

화면별로 달라지는 데이터와 표현은 남기고, 여러 목록에서 반복되는 테이블 기능을 공통 UI로 구성했습니다.

화면마다 구현할 때

  • 목록마다 테이블 구조와 기본 동작을 작성
  • 같은 기능도 화면별 표시와 조작 방식이 달라질 수 있음
  • 공통 동작을 바꿀 때 각 구현을 확인

공통 테이블을 사용할 때

  • 데이터와 컬럼을 전달해 기본 기능을 재사용
  • 같은 표시와 조작 기준을 여러 화면에 적용
  • 공통 동작의 수정 위치를 패키지로 모음
