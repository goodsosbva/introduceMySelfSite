# 권현성 | 프론트엔드 개발자

## 사이트의 의의

이 사이트는 경력과 기술 이름을 나열하는 데 그치지 않고, 짧은 시간 안에 제가 어떤 개발자인지 파악할 수 있도록 만든 소개 페이지입니다.

클라우드 관리 플랫폼, 자동차 정비 예약 서비스, 데이터 기반 웹 게임처럼 성격이 다른 서비스에서 사용자가 흐름을 쉽게 이해하고 일관되게 사용할 수 있도록 고민해 온 경험을 담았습니다. 개인 프로젝트와 회사 실무 경험을 나눠, 각 경험의 맥락과 역할도 구분해 볼 수 있습니다.

> 복잡한 운영 화면을 예측 가능한 코드 구조로 만들고, 일관된 사용 흐름을 만드는 프론트엔드 개발자입니다.
